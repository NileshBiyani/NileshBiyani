## About

I build **scalable, secure backend systems** — the invisible plumbing that lets products serve millions of users without falling over. My day-job is at a security-software leader (Black Duck / Synopsys), and outside that I contribute to open-source and design AI-native systems from the ground up.

I think about systems the way an architect thinks about a city: what fails first at 10× traffic, where the tenant boundaries sit, how the audit trail survives a decade, how a single query at 3 AM must never leak one company's data into another's dashboard.

- **4+ years** shipping production Java, Spring Boot, distributed systems, and security-critical services.
- **Learning by building** — RAG systems, LLM agents, multi-tenant SaaS, event-driven architectures.
- Interested in **HR-tech, security, developer tooling** — problems where architecture decisions compound.
- Currently deepening: **AI Engineering**, MCP, LangGraph, vector search, evals.
- Off-keyboard: cycling, gym, and a very active side-quest reading list.

## How I Work

- **API-first, docs-first, test-first.** If it's not in an OpenAPI spec, an ADR, and a test — it doesn't ship.
- **Every mutation is auditable.** Every request is traced. Every log line has a `trace_id`.
- **Ergonomics matter.** One command to boot the stack, one command to deploy, one to run every check.
- **Solo-friendly, team-ready.** Code so that the next contributor is productive in a week.
